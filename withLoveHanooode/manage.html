Connect your website

Connect once on each device you edit from (your laptop, your phone). After that, every save goes straight to your live shop.

  1. Open GitHub → New fine-grained token ↗ while signed in to your GitHub account.
  2. Name it Shop editor and set the expiration to one year.
  3. Under Repository access, choose Only select repositories and pick Portfolio_Summer2026.
  4. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else as it is.
  5. Generate the token, copy it and paste it below.
