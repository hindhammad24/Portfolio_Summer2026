## Directed Study Project
Created by Hind Hammad  
Directed Study Supervisor: Andrew Hawryshkewich

## Project Overview
This project is an interactive portfolio website developed as part of my Directed Study. 
The goal was to create more than a traditional portfolio website by designing an experience
that represents my identity as an interactive designer and developer and PAINTER.

Instead of only displaying final outcomes, I wanted the website to communicate my creative
process: how I experiment, sketch, build, code, and transform ideas into interactive experiences.
---

# Design Philosophy

## Making the Portfolio Personal
A major goal of this project was avoiding the feeling of a generic portfolio template.

I created a handmade visual identity inspired by my own creative process:
- custom illustrations
- hand-created icons
- painted navigation elements
- personal artwork
- animated interactions and gifs I created
- physical workspace metaphor
- mp4 created frame by frame 
- hand illustrated signiture 

The website represents the connection between my interests in:
- art
- design
- programming
- physical making
- emerging technologies
---

# Development Approach

## Structure
The website uses a modular structure:

portfolio/

assets/
- Images, illustrations, animations, videos, and project media

global/
- Shared styles and interactions (css and js)

sections/
- Individual website sections and their scripts/styles (css ad js)


## Global Components

### Navigation
Instead of a traditional hamburger menu, I created a paint palette navigation system.

The navigation uses:
- paint swatches
- hover colour changes
- custom illustrations

This keeps the interface connected to the artistic direction of the website.
---

### Custom Cursor

I created a custom paint brush cursor using JavaScript and Canvas.
The goal was to make the user's interaction feel like they are "painting" through the portfolio.
---

The website begins with a custom signature animation.

## Interactive and Static Experience Modes
Because interactive experiences can sometimes create accessibility or performance challenges,
I plan to explore two versions of the portfolio experience.

### Interactive Mode
The current direction of the portfolio focuses on:
- animations
- custom interactions
- dynamic transitions
- immersive storytelling
This version allows visitors to experience the portfolio as a creative exhibition.

### Static Mode
A simplified static version would provide an alternative experience for users who prefer:
- fewer animations
- faster loading
- reduced motion
- browsing without JavaScript dependency

This version would maintain:
- project information
- visual identity
- navigation
- content accessibility

while reducing interactive elements.
Creating both options would allow the portfolio to remain expressive while being accessible
to different types of users and devices.
